Video: https://www.youtube.com/watch?v=ZtXMkYSuR6E

Features:
  
  1) Records and updates temperature and humidity of area
  2) Displays temperature and humidity using an LCD
  3) Contains two modes (manual and automatic)
  4) If manual mode, the fan velocity is controlled by joystick input
  5) If automatic mode, the fan velocity changes based on the current temperature in the room
